# 🌾 AGRISHIELD AI

## Smart Irrigation & Crop Monitoring System

AGRISHIELD AI is a web-based smart irrigation concept designed to help farmers manage irrigation efficiently using modern technology. The project focuses on reducing water wastage, improving crop productivity, and supporting farmers through intelligent monitoring and automation.

The proposed system monitors important agricultural parameters such as soil moisture, temperature, humidity, rainfall, and water levels. Based on these values, a Machine Learning model can predict irrigation requirements and automate water supply.

A unique feature of the proposed solution is its ability to support farmers in rural areas with limited or no internet connectivity through GSM-based SMS notifications and automatic voice call alerts, making it suitable for both button phones and smartphones.
